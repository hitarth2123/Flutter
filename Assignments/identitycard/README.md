# Identity Card App

A Flutter project that displays a modern personal identity card with a profile image, name, role, details, and contact information.

## Output Preview

This project showcases the UI matching the attached output:

![Identity Card Output](https://github.com/hitarth2123/Flutter/blob/main/Assignments/OutputOfAssignment3.png)

## Features

- Blue-themed identity card design
- Profile photo circle avatar
- Name and profession section
- Personal details row for age, ID, and blood group
- Email info card at the bottom

## Run the project

```bash
flutter pub get
flutter run
```

## Main files

- `lib/main.dart` — UI design and card layout
- `pubspec.yaml` — Flutter project configuration
